# Formation Claude Code

## Contenu

### Dossier `pebbl`

Dossier de démarrage du fil rouge de la formation.

Il contient :

- `docs/pebbl.md` : informations sur Pebbl ;
- `img/` : images utilisées pendant les exercices.

### Dossier `etapes`

Versions intermédiaires du fil rouge de la formation.

Il contient :

- la codebase ;
- les fichiers clés ;
- les prompts de chaque étape.

Les dossiers `img/`, `vendor/` et `.git/` ne sont pas inclus.

## Outil
Le fichier outil_decision_claude_code.html est un outil pour vous aiguiller dans le type d'outil Claude Code à utiliser selon votre objectif.

## À préparer avant la formation

### Comptes

- Compte Claude / Anthropic : https://claude.ai
- Compte GitHub recommandé : https://github.com

## Logiciels à installer

### Obligatoires

- Navigateur Chrome ou équivalent
- Visual Studio Code ou équivalent : https://code.visualstudio.com
- Terminal fonctionnel
- Git : https://git-scm.com/downloads

Configuration Git minimale :

```bash
git config --global user.name "Votre Nom"
git config --global user.email "votre.email@example.com"
```

### Recommandés

- GitHub CLI `gh` : https://cli.github.com
- PHP 8 ou environnement local :
  - PHP : https://www.php.net/downloads
  - XAMPP : https://www.apachefriends.org
  - MAMP : https://www.mamp.info
- Composer : https://getcomposer.org/download
- Node.js : https://nodejs.org

Prévoir un accès Internet non bloqué vers :
