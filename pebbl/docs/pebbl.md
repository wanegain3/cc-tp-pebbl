# Pebbl — Documentation produit interne

## 1. Objectif du document

Ce document sert de référence interne pour comprendre Pebbl, son positionnement, ses fonctionnalités, son ton de marque et les éléments visuels disponibles.

Il doit aider toute personne qui travaille sur le produit, la communication, le site web ou l’interface à rester cohérente avec notre vision.

## 2. Qui nous sommes

Nous sommes Pebbl, une startup qui conçoit un objet lumineux connecté pensé pour accompagner les moments importants de la journée : travailler, respirer, bouger, se recentrer ou se détendre.

Nous voulons créer une alternative plus douce aux objets connectés classiques. Pebbl ne doit pas être perçu comme un gadget technologique bruyant, mais comme une présence discrète, utile et sensible dans l’espace.

Notre approche repose sur une idée simple : l’environnement influence notre attention, notre énergie et nos transitions. Pebbl aide à ajuster cet environnement sans effort.

## 3. Notre produit

Nom du produit : Pebbl

Slogan principal : Votre énergie change. L’espace suit.

Pebbl est un galet lumineux connecté. Il comprend une ligne lumineuse capable de changer de couleur et d’intensité.

L’objet peut être posé sur un bureau, une table de chevet, une étagère, dans un salon ou dans un espace de méditation.

Pebbl permet de créer une ambiance lumineuse adaptée à l’état d’esprit ou à l’activité du moment.

Notre produit est pilotable depuis une application disponible sur smartphone et sur montre connectée.

## 4. Notre vision

Nous ne voulons pas créer une simple lampe.

Nous voulons créer un objet de transition : un compagnon discret qui aide à passer d’un état à un autre sans changer d’espace.

Pebbl peut accompagner plusieurs moments :

* commencer une session de travail ;
* entrer dans un moment de concentration ;
* prendre une pause ;
* méditer ;
* respirer ;
* bouger ;
* revenir au calme ;
* ritualiser la fin de journée.

Pebbl doit être simple à comprendre, agréable à utiliser et facile à intégrer dans un intérieur.

## 5. Notre positionnement

Pebbl se situe entre :

* un objet design ;
* une lampe d’ambiance ;
* un compagnon de concentration ;
* un accessoire bien-être ;
* une interface douce entre l’utilisateur et son environnement.

Nous voulons éviter le positionnement “gadget connecté”.

Pebbl doit évoquer :

* la présence ;
* l’intention ;
* le calme ;
* le focus ;
* le rythme ;
* la transition ;
* la lumière juste au bon moment.

## 6. Notre cible

Pebbl s’adresse principalement à des personnes qui veulent mieux gérer leur attention, leur énergie et leurs transitions au quotidien.

Nos utilisateurs potentiels sont notamment :

* les télétravailleurs ;
* les indépendants ;
* les créatifs ;
* les personnes qui travaillent beaucoup sur écran ;
* les personnes sensibles au design ;
* les personnes intéressées par la méditation, le bien-être ou la productivité ;
* les personnes qui veulent créer des rituels simples dans leur journée.

Notre cible aime les objets sobres, beaux, utiles et faciles à intégrer dans un espace de vie ou de travail.

## 7. Notre ton de marque

Notre ton doit être :

* calme ;
* clair ;
* premium ;
* sensoriel ;
* humain ;
* sobre ;
* légèrement technologique, mais jamais froid.

Nous voulons parler de technologie avec douceur.

Nous devons éviter :

* le jargon technique ;
* les promesses médicales ;
* le vocabulaire trop futuriste ;
* les formulations anxiogènes ;
* les phrases trop “startup révolutionnaire” ;
* les formulations qui donnent l’impression que Pebbl surveille l’utilisateur.

Pebbl doit donner une impression de maîtrise, de simplicité et de présence.

## 8. Modes de fonctionnement

Pebbl comprend deux modes principaux : le mode manuel et le mode adaptif.

### Mode manuel

Dans ce mode, l’utilisateur choisit directement la couleur et l’intensité de Pebbl.

Il peut aussi sélectionner une ambiance focus selon son intention du moment :

* concentration ;
* méditation ;
* énergie.

Le mode manuel est utile quand l’utilisateur sait précisément quelle ambiance il veut créer.

### Mode adaptif

Dans ce mode, Pebbl s’adapte à la journée et à l’intention de l’utilisateur.

Pebbl peut ajuster automatiquement la couleur et l’intensité de la lumière selon :

* l’heure de la journée ;
* la luminosité ambiante ;
* le contexte d’usage ;
* l’activité détectée via les appareils connectés de l’utilisateur.

Nous devons présenter le mode adaptif comme une aide discrète, pas comme une surveillance.

Formulation à privilégier :

Pebbl tient compte de votre rythme, de la lumière ambiante et des signaux de vos appareils connectés pour ajuster l’atmosphère au bon moment.

Formulation à éviter :

Pebbl écoute ce qui se passe autour de vous et analyse vos comportements.

## 9. Ambiances focus

Pebbl propose trois ambiances focus.

### Focus concentration

Couleur dominante : bleu.

Cette ambiance accompagne les moments de travail, de lecture, d’écriture ou de concentration.

Elle doit évoquer :

* la clarté ;
* le calme ;
* l’attention ;
* la stabilité.

La luminosité peut s’ajuster selon le niveau de stress ou l’intensité du moment, mais nous devons éviter les promesses trop médicales ou scientifiques.

### Focus zen

Couleur dominante : doré.

Cette ambiance accompagne les moments de méditation, de respiration ou de pause.

Si Pebbl est connecté à une montre, sa lumière peut varier progressivement en intensité pour suivre le rythme de respiration.

Elle doit évoquer :

* la chaleur ;
* le calme ;
* la respiration ;
* le recentrage.

### Focus énergie

Couleur dominante : rouge.

Cette ambiance accompagne les moments de mouvement, d’échauffement ou de sport.

Si l’utilisateur porte son smartphone ou sa montre, la lumière peut réagir au rythme de ses pas.

Elle doit évoquer :

* l’élan ;
* le mouvement ;
* la motivation ;
* l’intensité.

## 10. Application mobile et montre

Pebbl peut être contrôlé depuis une application sur smartphone et sur montre connectée.

L’application permet notamment de :

* changer de mode ;
* choisir une couleur ;
* régler l’intensité ;
* sélectionner une ambiance focus ;
* activer ou désactiver le mode adaptif.

L’application doit être présentée comme simple, claire et rapide à utiliser.

Elle ne doit pas donner l’impression d’être complexe ou réservée aux utilisateurs très techniques.

## 13. Contraintes de discours

Nous ne devons pas présenter Pebbl comme un dispositif médical.

Nous ne devons pas promettre que Pebbl réduit réellement le stress, soigne l’anxiété, améliore le sommeil ou augmente scientifiquement la concentration.

Formulations à privilégier :

* “accompagne vos moments de concentration” ;
* “aide à créer une ambiance propice au calme” ;
* “vous permet de ritualiser vos transitions” ;
* “s’adapte à votre intention” ;
* “crée une présence lumineuse adaptée au moment”.

Formulations à éviter :

* “réduit votre stress” ;
* “améliore vos performances” ;
* “corrige votre respiration” ;
* “détecte vos émotions” ;
* “surveille votre environnement” ;
* “analyse votre comportement”.
