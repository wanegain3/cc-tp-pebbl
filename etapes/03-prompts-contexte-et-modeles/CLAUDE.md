# CLAUDE.md

Ce fichier fournit des instructions à Claude Code (claude.ai/code) pour travailler avec le code de ce dépôt.

## Langue de travail

Nous travaillons en français. Toutes les réponses, suggestions et fichiers générés doivent être en français.

## Contexte du projet

C'est un TP (travail pratique) pour construire une landing page marketing pour **Pebbl**, un objet lumineux connecté fictif. Le brief produit complet se trouve dans `@docs/pebbl.md` — le lire avant de générer tout contenu ou interface.

## Contraintes de marque

- Ne jamais faire de déclarations médicales ou liées à la santé (ex. : "réduit le stress", "améliore le sommeil", "booste les performances").
- Ne jamais utiliser un langage de surveillance (ex. : "analyse votre comportement", "écoute votre environnement").
- Ton : calme, premium, sensoriel, humain — jamais froid ni trop technique.
