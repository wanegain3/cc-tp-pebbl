# Règles HTML/CSS

- Répondre et commenter le code en français.
- Garder la page en HTML/CSS/JS vanilla, sans framework.
- Utiliser les variables CSS définies dans `:root` pour les couleurs, espacements et rayons.
- Éviter les styles inline dans le HTML, sauf exception très ponctuelle.
- Structurer les grandes parties avec des sections identifiées (`#hero`, `#benefices`, `#faq`, etc.).
- Utiliser uniquement les images présentes dans `/img/`.
- Ajouter un attribut `alt` descriptif en français sur chaque image.
- Ne pas employer de promesses médicales ou de langage de surveillance.
- Vérifier le responsive mobile après toute modification importante.
